# Analyse des données RH – 500 travailleurs

## Présentation
Projet d'analyse des données de 500 travailleurs
réalisé avec Microsoft Excel et Power BI.

## Objectifs
- Analyser les salaires.
- Étudier les effectifs par département.
- Analyser la masse salariale.
- Comparer les performances.
- Créer un tableau de bord interactif.

## Outils utilisés
- Microsoft Excel
- Microsoft Power BI
- Power Query
- DAX

## Contenu
- 01_EXCEL : analyses et calculs Excel.
- 02_POWER_BI : rapport Power BI.
- 03_DOCUMENTATION : documentation du projet.

## Auteur
Projet réalisé dans le cadre d'un TP
de Data Analysis.
